按需渲染

这个话题可能对很多人来说显而易见，但以防万一......大多数 Three.js 示例都是连续渲染的。换句话说，它们设置了一个 requestAnimationFrame 循环或“rAF 循环”，像这样：

function render() {
  ...
  requestAnimationFrame(render);
}
requestAnimationFrame(render);

对于有动画效果的东西，这是有意义的，但对于没有动画效果的东西呢？在这种情况下，连续渲染会浪费设备的性能，如果用户使用的是便携式设备，还会浪费用户的电池电量。

解决这个问题最直接的方法是：开始时渲染一次，然后仅在发生某些变化时重新渲染。这些变化包括：纹理或模型最终加载完成、从某个外部源接收到数据、用户调整设置或相机、或提供其他相关输入。

让我们以响应式设计文章中的一个例子为基础，修改它以使其按需渲染。

首先，我们将添加 OrbitControls，这样就有了可以响应其变化并触发渲染的东西。

然后我们只需要渲染一次：

render();

每当 OrbitControls 改变相机设置时，我们需要重新渲染。幸运的是，OrbitControls 会在任何变化发生时分发一个 change 事件。

controls.addEventListener('change', render);

我们还需要处理窗口大小改变的情况。以前由于我们是连续渲染的，所以会自动处理，但现在我们不再连续渲染，因此当窗口大小改变时需要重新渲染。

window.addEventListener('resize', render);

这样就得到了一个按需渲染的示例。

OrbitControls 有一些选项可以添加一种惯性效果，使其感觉不那么生硬。我们可以通过将 enableDamping 属性设置为 true 来启用它。

controls.enableDamping = true;

启用了 enableDamping 后，我们需要在我们的渲染函数中调用 controls.update，以便 OrbitControls 能够在平滑移动时持续为我们提供新的相机设置。但是，这意味着我们不能直接从 change 事件中调用 render，因为这样会导致无限循环。控件会发送一个 change 事件并调用 render，而 render 又会调用 controls.update。controls.update 会再发送另一个 change 事件。

我们可以通过使用 requestAnimationFrame 来调用 render，但需要确保我们只请求一帧（如果还没有请求的话）。这可以通过一个变量来跟踪是否已经请求了一帧来实现。

+let renderRequested = false;

function render() {
+  renderRequested = false;

  if (resizeRendererToDisplaySize(renderer)) {
    const canvas = renderer.domElement;
    camera.aspect = canvas.clientWidth / canvas.clientHeight;
    camera.updateProjectionMatrix();
  }

  renderer.render(scene, camera);
}
render();

+function requestRenderIfNotRequested() {
+  if (!renderRequested) {
+    renderRequested = true;
+    requestAnimationFrame(render);
+  }
+}

-controls.addEventListener('change', render);
+controls.addEventListener('change', requestRenderIfNotRequested);

我们可能也应该对窗口大小调整使用 requestRenderIfNotRequested：

-window.addEventListener('resize', render);
+window.addEventListener('resize', requestRenderIfNotRequested);

让我们再添加一个简单的 lil-gui GUI，并使其更改也能按需触发渲染。

import * as THREE from 'three';
import {OrbitControls} from 'three/addons/controls/OrbitControls.js';
+import {GUI} from 'three/addons/libs/lil-gui.module.min.js';

我们将允许设置每个立方体的颜色和 x 轴缩放比例。为了能够设置颜色，我们将使用在光照文章中创建的 ColorGUIHelper。

首先，我们需要创建一个 GUI：

const gui = new GUI();

然后，为每个立方体创建一个文件夹，并添加两个控件：一个用于 material.color，另一个用于 cube.scale.x。

function makeInstance(geometry, color, x) {
  const material = new THREE.MeshPhongMaterial({color});

  const cube = new THREE.Mesh(geometry, material);
  scene.add(cube);

  cube.position.x = x;

+  const folder = gui.addFolder(`Cube${x}`);
+  folder.addColor(new ColorGUIHelper(material, 'color'), 'value')
+      .name('color')
+      .onChange(requestRenderIfNotRequested);
+  folder.add(cube.scale, 'x', .1, 1.5)
+      .name('scale x')
+      .onChange(requestRenderIfNotRequested);
+  folder.open();

  return cube;
}

如上所示，lil-gui 控件有一个 onChange 方法，你可以传入一个回调函数，当 GUI 更改某个值时，这个回调函数就会被调用。在我们的例子中，我们只需要它调用 requestRenderIfNotRequested。调用 folder.open 会使文件夹初始状态为展开。

我希望这能让您了解如何让 three.js 按需渲染，而不是连续渲染。按需渲染 three.js 的应用程序或页面并不常见，因为大多数使用 three.js 的页面要么是游戏，要么是 3D 动画艺术。但有些页面可能更适合按需渲染，例如：地图查看器、3D 编辑器、3D 图表生成器、产品目录等等。
